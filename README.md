## 🛠️ Setup & Local Installation

### 🌐 MACHA HUB Dashboard

When the bot starts, it also serves a branded control panel at `http://localhost:3000` (set `PORT` to change the port). The dashboard provides:

* **10 persistent saver sessions**. Every saver gets its own child process and auth directory under `sessions/saver-N`, with real Baileys pairing-code requests.
* **Chatbot personalization** and the `.chatbot "personalization" on` command.
* **Dynamic profile rotation**. Add `.jpg` or `.png` images to `assets/profiles`, choose an interval, and enable it from the dashboard.
* Live socket status and clear error messages when WhatsApp is not ready.

Pairing codes are generated by an isolated WhatsApp socket for the selected saver; the dashboard does not fake a successful connection. Keep the pairing code private and link it in WhatsApp under **Linked devices**. Ten concurrent saver processes require enough RAM/CPU on the host.

### 🚀 Deploy on Render

This repository includes [`render.yaml`](./render.yaml). Create a new **Blueprint** on Render from the repository, then set `PHONE_NUMBER` in the service environment (digits only, including country code). Set `GEMINI_API_KEY` only if your AI provider requires it. The included persistent disk keeps `session/` and saver credentials available after restarts.

If Render reports `Cannot find module`, trigger **Manual Deploy → Clear build cache & deploy** after pulling the latest `package.json`. The build must run `npm install --legacy-peer-deps` before `npm start`.

Netlify can publish the static `web/` folder, but it cannot run the WhatsApp bot or its Node API. If you use Netlify for the frontend, replace `YOUR-RENDER-SERVICE` in [`netlify.toml`](./netlify.toml) with the Render service hostname.

### Prerequisites
*   **Node.js** (v18 or higher recommended)
*   **Git** installed on your server environment
*   **MT Manager** or a secure terminal wrapper

### Step-by-Step Installation

1. **Clone the repository:**
```bash
    git clone [https://github.com/your-github-username/macha-ai-bot.git](https://github.com/your-github-username/macha-ai-bot.git)
    cd macha-ai-bot
    ```

2. **Install all framework dependencies:**
```bash
    npm install
    ```

3. **Deploy the Engine:**
```bash
    npm start
    ```

4. **Authentication:**
    Scan the generated QR code or deploy using the native pairing code structure to safely link your primary device.
